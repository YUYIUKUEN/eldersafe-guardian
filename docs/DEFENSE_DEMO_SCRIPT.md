# ElderSafe Guardian — 5 分鐘答辯示範劇本

照住以下步驟操作即可。建議開兩個瀏覽器視窗：管理員（左）＋義工（右）。

---

## 0. 答辯前準備（約 2 分鐘，唔計入示範時間）

```bash
# 1) 填好 apps/admin/.env.local（Supabase URL + anon + service role）
# 2) 種入答辯示範資料
pnpm seed:defense-demo -- --clean

# 3) 啟動網站（三個都行；答辯最少要 admin + volunteer）
pnpm --filter @eldersafe/admin run dev       # http://localhost:3003
pnpm --filter @eldersafe/volunteer run dev   # http://localhost:3002
```

## 1. 開場＋儀表板（0:00–0:40）

1. 打開 `http://localhost:3003/zh-HK/login`，登入管理員。
2. 停在儀表板，指一指統計：長者、已批准義工、待接單、進行中緊急、本月已完成。
3. **講稿：**  
   「系統分三個網站：長者、義工、管理員，共用同一個 Supabase 後端。管理員可以即時睇整體狀況。」

---

1. 左側導覽 → **排行榜與證書**（`/zh-HK/leaderboard`）。
2. 確認本月月份，指出 Top 3：
   - 第 1：王志明（約 90 分）
   - 第 2：陳美玲（約 65 分）
   - 第 3：林志強（約 45 分）
3. **講稿：**  
   「積分只會喺長者確認完成之後先加。規則係基本 10 分，服務超過 30 分鐘加 5，評分 4 星或以上再加 5。排行榜按本月積分排序，管理員可以結算 Top 3 證書。」
4. （可選，約 15 秒）右邊視窗用王志明登入義工站 → **排行榜**，顯示同一排名。

## 4. 日誌（3:20–4:20）

1. 左側導覽 → **日誌**（`/zh-HK/logs`）。
2. 示範篩選：
   - 動作類別選 **help** 或 **volunteer**
   - 或揀日期範圍涵蓋今個月
3. 指幾行：例如 `elder.help_request.create`、`volunteer.help_request.accept`、`admin.volunteer.approve`。
4. **講稿：**  
   「所有關鍵操作都會寫入 append-only 日誌，管理員可以篩選同匯出 CSV，方便稽核同答辯時證明系統有完整紀錄。」

---

## 5. 緊急事件收尾（4:20–5:00）

1. 左側導覽 → **緊急事件**（`/zh-HK/emergencies`）。
2. 打開 **進行中** 嗰單（陳婆婆），指地圖／位置軌跡同警方分享連結。
3. **講稿：**  
   「長者撳紅色緊急掣之後，會倒數、撥號，同時建立緊急事件同即時位置分享。管理員同警方連結可以跟進。」
4. 收結一句：  
   「以上就係排行榜、活躍度、日誌同緊急事件嘅管理端示範；義工端可以接單加分，長者端用大字大掣完成求助同確認。」

## 超時時可刪減

| 優先 | 段落 | 可刪原因 |
|------|------|----------|
| 必做 | 排行榜 + 活躍度 | 答辯重點 |
| 次要 | 日誌篩選 | 可只講一句＋指畫面 |
| 可刪 | 義工端排行榜 | 與管理端重複 |
| 可刪 | 緊急事件詳情 | 改為儀表板紅色提示一句帶過 |

---

## 常見問題（預備答）

- **點解何小雯唔喺排行榜？** 未批准義工不可接單，亦唔會計入排行榜。
- **點解有完成單但未加分？** 要長者確認完成（或管理員強制確認）先寫入 `points`。
- **活躍度同積分有咩分別？** 積分獎勵服務質素／時長；活躍度反映本月參與頻率。
- **點解黃太太活躍度低但仍有紀錄？** 佢嘅求助單刻意放喺上個月，本月 helpCount = 0。
